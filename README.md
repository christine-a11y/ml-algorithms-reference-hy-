## 📚 Բովանդակություն

### 1. Վերահսկվող Ուսուցում (Supervised Learning)
* **Ռեգրեսիա:** Գծային ռեգրեսիա (Linear Regression), Գրադիենտային իջեցման օպտիմիզացիա, Գնահատման մետրիկաներ
* **Դասակարգում:** Լոգիստիկ ռեգրեսիա, Հենակետային վեկտորների մեթոդ (SVM), Նայվ Բայես (Naive Bayes), Որոշումների ծառեր (Decision Trees), Անսամբլներ (Random Forest)

### 2. Չվերահսկվող Ուսուցում (Unsupervised Learning)
* **Կլաստերիզացիա:** K-Means, DBSCAN, Հիերարխիկ կլաստերիզացիա, Գաուսյան խառնուրդների մոդելներ (GMM)
* **Չափայնության Կրճատում:** Գլխավոր բաղադրիչների վերլուծություն (PCA)

### 3. Մաթեմատիկա և Վիճակագրություն ML-ի համար
* **Գծային Հանրահաշիվ և Մաթ․ Վերլուծություն:** Մատրիցային գործողություններ, Սեփական արժեքներ/վեկտորներ, Մասնակի ածանցյալներ, Գրադիենտներ
* **Հավանականություն և Վիճակագրություն:** Հավանականային բաշխումներ, Բայեսի թեորեմ, Վարկածների ստուգում, A/B թեստավորման հիմունքներ
* **Օպտիմիզացիա:** Կորստի ֆունկցիաներ (Loss Functions), Գրադիենտային իջեցման տարբերակներ
